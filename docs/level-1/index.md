# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: understand what Docker is and why it exists, get it installed and
running, and be able to write a Dockerfile, build an image, run a container
with a mounted volume and a mapped port, and push/pull from a registry.

10. [Project — Containerize a Small App](10-project-containerize-app.md)

By the end of this level you'll be able to write a Dockerfile from scratch,
build and tag an image, run it as a container with persistent storage and a
published port, inspect and manage its lifecycle, and share the image
through a registry.
